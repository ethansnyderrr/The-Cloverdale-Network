# Rack and Display

## Rack
GeeekPi 10" rack mount housing the server, switch, and storage.

## Status Display
GeeekPi 10" rack-mount LCD (HDMI + USB) connected directly to the EliteDesk's HDMI output. Displays a live status dashboard showing each guest's state plus the switch's online/offline status.

See [`software/dashboard/`](../software/dashboard/).
